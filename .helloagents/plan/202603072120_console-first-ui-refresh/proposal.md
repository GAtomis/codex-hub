# Console First UI Refresh

- Created: 2026-03-07 21:20
- Type: implementation
- Scope: hub-frontend

## 1. 需求

- 面向熟悉 Codex CLI / Codex App 的用户，降低当前 Hub 的理解和使用成本。
- 以项目会话为主线重组页面，而不是以表格和底层模块为主线。
- 保留 Minecraft 风格，但把它提升为统一视觉系统，而不是局部皮肤。

## 2. 方案

- 首页改为 Console First 入口页：突出继续工作、项目卡片、运行态摘要。
- 项目页改为单项目主工作台：会话区为核心，线程历史和项目状态作为辅助。
- 线程页强化沉浸式对话体验，减少调试信息对主阅读流的打断。
- 全局样式统一按钮、输入、卡片、表格、面板、空态和状态灯，增强像素感和层级。

## 3. 验收

- 用户在首页 5 秒内可以找到进入项目会话的主入口。
- 项目页主视觉明确以“会话”作为第一优先级。
- 历史线程选择、当前线程状态、任务状态具有更强可发现性。
- Minecraft 风格在首页、项目页、线程页表现统一。
